# VEYLIX — GATE BASELINE (2026-11-04)

**Why this file exists.** Before the system-by-system completion pass started, the
working tree carried **299 uncommitted changes** against `main` — 21 migrations,
122 routes and 504 tests that had never been committed. Without a recorded
baseline, a later "it still passes" or "this fixed it" claim would have nothing to
compare against, and a regression introduced by a *new* change would have been
indistinguishable from the pre-existing state.

This is that baseline. Every later gate compares against the **Result** column,
and any number that differs must be explained in this file or in
`docs/IMPROVEMENT_LEDGER.md`.
